如何填写 Data safety 与隐私政策

下面按「如何做」整理要点，便于对照官方后台逐步完成。

操作要点

  • 梳理应用实际收集与分享的数据类别。
  • 声明需与代码行为、第三方 SDK 一致。
  • 隐私政策写清收集目的、存储与用户权利。
  • 变更 SDK 或登录方案后同步更新表单。
  • 以 Console 表单字段与政策要求为准。
